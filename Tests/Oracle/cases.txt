# Cases for the Vim oracle. Real Vim plays each one (regenerate.sh) and
# OracleTests replays it in VimKit and compares the text, the cursor, the
# mode and the unnamed register.
#
#   [name]          a unique name
#   keys <keys>     keys in Vim notation, the rest of the line: dw, ciwx<Esc>,
#                   :s/a/b/<CR>, <C-v>, <lt> for a literal <, <Space> for a
#                   trailing space
#   at <line> <col> where the cursor starts, 1-based (default 1 1)
#   | text          the text, one line each ("|" alone is an empty line)
#
# End in normal mode: finish insert with <Esc> and visual with an operator.
# Leave out what depends on the window (H, M, L, scrolling, gj).
# After editing, run Tests/Oracle/regenerate.sh and commit the JSON.
